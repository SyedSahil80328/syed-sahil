<strong>FallGuard:</strong> Time-Series Deep Learning for Fall Detection<br>
• Built a fall detection system using wearable sensor data, avoiding limitations of vision-based approaches (privacy, camera dependency)<br>
• Processed triaxial accelerometer signals and handled class imbalance using SMOTE with filtering of unrealistic samples<br>
• Used an InceptionTime-based architecture to capture temporal patterns in motion data<br>
• Achieved ~98.8% accuracy on the KFall dataset, outperforming LSTM, TCN, and Transformer-based baselines<br><br>
<strong>TECH STACK:</strong> Python | PyTorch | tsai | scikit-learn<br>
