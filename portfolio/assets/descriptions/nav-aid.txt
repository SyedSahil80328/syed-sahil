<strong>NavAid:</strong> Assistive Navigation System for the Visually Impaired  
• Built a real-time assistive system on Raspberry Pi to detect objects and provide voice-guided alerts<br>
• Implemented YOLO-based object detection supporting ~91 object classes with distance-based notifications<br>
• Processed live camera input for real-time detection and user feedback<br>
• Explored GPS-based navigation, but faced hardware limitations; focused on reliable object detection and alert system<br><br>
<strong>TECH STACK:</strong> Python | OpenCV | YOLO | Raspberry Pi<br>
