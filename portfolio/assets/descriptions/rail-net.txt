<strong>RailNet: </strong> Web-based Railway Management System
• Built a web application to manage train schedules and booking records with authenticated access<br>   
• Implemented backend using Flask with session management and MySQL for structured data storage<br> 
• Applied Triple DES (TDES) encryption for password protection as part of learning secure system design concepts<br>  
• Added features like PDF ticket generation and sequential voice announcements (Tamil → Hindi → English) using gTTS, inspired by real-world railway systems  <br><br>
<strong>Tech:</strong> Python, Flask, MySQL, HTML, CSS, JavaScript<br>
